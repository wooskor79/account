# Quiz Engine Validation & Testing Guide

회계 퀴즈 풀이 및 채점 로직의 무결성을 보장하기 위한 검증 가이드입니다.

## 1. 분개 문제(Journal Entry) 검증 규칙
- **대차평균의 원리**: 차변(Debit) 합계 금액과 대변(Credit) 합계 금액이 항상 일치하는지 자동 검증.
- **계정과목 코드 매핑**: 입력된 계정명이 유효한 계정과목 마스터 데이터(ccounts.js, ccounts_1.js)에 존재하는지 확인.
- **동의어 및 띄어쓰기 유연성**: '외상매출금'과 '외상 매출금' 등 입력값 정규화(Trim, 공백 제거) 후 정답 비교.

## 2. 필기/객관식 문제 검증
- 문제 지문, 보기 1~4번, 정답 번호, 해설의 존재 여부 및 형식 무결성 검증.
- 정답 인덱스 범위(1~4) 유효성 체크.

## 3. 회귀 테스트(Regression Test)
- 채점 엔진 로직 수정 시 기존 문제 풀이 및 정답 샘플 데이터셋을 대상으로 배치 채점 테스트 실행하여 채점 오류 방지.
