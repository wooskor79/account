[ data 폴더 파일 역할 안내 ]

이 폴더는 전산회계 웹사이트 및 맞춤학습 엔진에서 데이터베이스(DB)를 대신하여 사용하는 JSON 파일들이 모여있는 곳입니다. 각 파일의 역할은 다음과 같습니다.

1. 계정 및 진행도 관련 (맞춤학습)
- learning_users.json : 맞춤학습 시스템에 가입한 회원의 계정 정보(ID, 이름, 암호화된 비밀번호, 최근 접속일 등)를 저장합니다.
- learning_progress.json : 각 회원별 단원 학습 진도율, 문제 풀이 달성도(필기/분개 맞춘 개수 등)를 저장합니다.
- user_streaks.json : 회원들의 연속 정답 기록(콤보/스트릭) 데이터를 저장하여 게미피케이션(동기부여)에 사용합니다.
- user_wrong_notes.json : 회원들이 퀴즈나 분개 문제에서 틀렸던 문항들을 모아두는 오답노트 데이터입니다.

2. 문제 및 통계 관련
- question_stats.json : 개별 문항(문제)별로 전체 사용자들의 정답률, 오답률, 선택지 통계를 누적하여 저장합니다.
- high_scores.json : 문제 풀이 시 높은 점수나 좋은 기록을 달성한 랭킹/최고 점수 데이터를 보관합니다.
- section_titles.json : 맞춤학습 커리큘럼의 단원명(섹션 타이틀)이나 요약 카테고리 정보 등 메타데이터를 저장합니다.

3. 사이트 운영 및 자료실 관련
- files.json : 메인 자료실 등에서 관리하는 전체 업로드 파일 목록과 다운로드 횟수 등의 정보를 저장합니다.
- files_grade1.json : 1급 자료실(전산회계 1급) 전용으로 분류된 파일 목록 및 메타데이터를 저장합니다.
- files_grade2.json : 2급 자료실(전산회계 2급) 전용으로 분류된 파일 목록 및 메타데이터를 저장합니다.
- site_settings.json : 웹사이트의 전역 설정, 관리자 설정 등의 설정 값을 저장합니다.
- visitors.json : 웹사이트의 일일 방문자 수, 누적 방문자 수 등 방문 통계 카운터 데이터를 저장합니다.
